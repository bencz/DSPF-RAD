# 驗證檢查清單

每次交付草稿前，先跑過這一輪。檢查由機械性到判斷性排列。

## 機械性檢查（可搜尋）

在草稿中搜尋下列樣式。程式碼區塊與引用文字之外的每一處命中都是違規。

| 搜尋 | 違規 | 修正 |
|---|---|---|
| `'ll`、`'re`、`'ve`、`n't`、`it's` | 縮寫（規則 4.2） | 展開。 |
| `has been`、`have been`、`had been` | 現在／過去完成式（規則 3.4） | 簡單過去式或簡單現在式。 |
| `has` / `have` ＋ 過去分詞 | 現在完成式（規則 3.4） | 簡單過去式。 |
| `should`、`would`、`may`、`might`、`could` | 未核准的情態動詞（規則 3.2） | 見 SKILL.md 的情態動詞階梯。 |
| `is being`、`are being`、`was being` | 進行式被動（規則 3.4、3.5） | 主動語態、簡單時態。 |
| `, making`、`, allowing`、`, enabling`、`, ensuring` | 作動詞用的「-ing」子句（規則 3.5） | 用有真實主詞的新句子。 |
| `;` | 分號（規則 8.1） | 拆成兩句。 |
| `e.g.`、`i.e.`、`etc.` | 拉丁縮寫（GR-6） | "for example"、"that is"、列舉項目。 |
| `simply`、`easily`、`seamlessly`、`robust` | 填充詞（無事實） | 刪除。 |
| ` if `、` when `（句中被動式的位置） | 條件後置（規則 5.4） | 把條件移到句首，加逗號。 |

## 可計數的檢查

1. **句長。** 數每句的字數。程序文上限：20。描述文上限：25。註記：25。
   反引號內的指令、帶單位的數字與識別符各算一個詞（規則 8.6）。
2. **段落大小。** 每段最多六句（規則 6.6）。
3. **多詞名詞。** 超過三個詞的名詞鏈 → 用介係詞拆開（規則 2.1）。
4. **每句指示數。** 一句一條，除非動作同時發生（規則 5.2）。

## 判斷性檢查

5. **分類。** 每一段是否乾淨地歸為程序文或描述文？程序用祈使句，描述文絕不用祈使句。
6. **語態。** 有被動句嗎？執行者是否真的未知、且該段是描述文？否則改成主動（規則 3.6）。
7. **條件位置。** 每個「if/when」都在它的指令之前，帶逗號（規則 5.4）。
8. **同義詞輪換。** 全篇每個概念只用一個詞（規則 1.11、9.4）。掃 check/verify/confirm、config/settings、run/execute。
9. **警告。** 指令或條件在前，風險在後（規則 7.2、7.3）。
10. **完整性。** 冠詞在、「that」在「make sure」之後、不是電報體（規則 4.2）。
11. **不可改動項完好。** 程式碼、識別符、引用的錯誤與專有名詞都未經更動。

## 回報違規時（檢查模式）

每一項違規給出：規則編號、違規文字、合規改寫。只引用 SKILL.md 中存在的規則編號。
當使用者要求 STE 合規時，在報告結尾加上這段聲明：「沒有任何工具能保證 ASD-STE100 合規。最終批准權在撰寫者手上。官方標準在 asd-ste100.org 免費下載。」

## 簡明中文模式（中文輸出）

輸出語言為中文時，在英文檢查之上加跑這幾輪（詳見 SKILL.md「中文輸出模式」一節）。

### 機械性檢查（可搜尋）

| 搜尋 | 違規 | 修正 |
|---|---|---|
| `進行了`、`實現了`、`做出了`、`進行＋動詞` | 動詞名詞化（規則 3.7 中文版） | 直接動詞：「檢查配置」「優化」 |
| `賦能`、`閉環`、`抓手`、`對齊`、`顆粒度`、`復盤`、`沉澱`、`落地`、`痛點`、`一站式` | 中文 AI 味空話 | 見 SKILL.md 中文 AI 味替換表 |
| `值得注意的是`、`需要注意的是`、`綜上所述`、`與此同時` | 填充詞 | 刪除 |
| 分號串接≥3 個完整句 | 分號濫用（規則 8.1 中文版） | 拆句；僅並列分句可用「；」 |
| `—`、`–`、emoji（表情符號） | 未核准標點／圖示（中文文法調適） | **重組句式或直接省略——不要只替換成逗號句號** |
| `確保`、`檢查`、`驗證`、`保證`（同篇混用） | 同義詞輪換（規則 1.11 中文版） | 每組只留一個 |

### 可計數的檢查

- **中文字數**：程序文 ≤30、描述文 ≤40（英文 20/25 字詞的 1.5 倍密度映射）。
- **「的」鏈**：名詞鏈超過 3 個修飾層 → 拆句或冒號補述（規則 2.1 中文版）。
- **指代**：光禿禿的「這」→「此做法／該功能」（GR-7 中文版）。

### 判斷性檢查

- **時點**：過去事件用「已／在…時」，未來用「將／會」；不用「進行了」敷衍時間資訊。
- **條件前置**：每個「如果／當」在句首，逗號後接指令。
- **被動語態**：執行者已知 → 主動；只有執行者未知才用「被／由」。
- **警告**：「警告：／注意：」分級使用，指令在前、風險在後，不用客套語。
