# simple-chinese

以 ASD-STE100（STE）的規則撰寫、改寫技術文件：輸出繁體中文，程式碼與關鍵術語保留英文——清晰、無歧義、沒有 AI 廢話。

## 例子

**改寫前：** 為進一步提升用戶體驗，我們深度賦能了底層架構，並實現了完整閉環。

**改寫後：** 我們升級了架構。升級後，載入時間從 3 秒降為 1 秒。

## 用法

> 把這段改成簡單易明的中文
> 中文去AI味：重寫這份上線說明
> de-slop 這個 README（英文模式）
> 檢查這段技術文字（檢查模式：回報規則編號＋違規文字＋合規改寫）

把整個 `simple-chinese` 目錄放入你的 agent skills 目錄（如 `~/.claude/skills/`）即可使用。
